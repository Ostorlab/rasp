# ELF RASP Implementation Plan

> For agentic workers: use subagent-driven-development for the native runtime and independent reviews; execute remaining integration work in this session with test-first checks.

**Goal:** Produce runnable ELF outputs with injected checks, runtime network instrumentation and backend enforcement, verified before Android.

**Architecture:** LIEF rewrites the executable dependency table. A C/OpenSSL shared runtime verifies a signed manifest, scans continuously and signs backend evidence. Python provides the packer, protocol and reusable authorizer/reference server.

**Tech stack:** Python 3.10+, LIEF, cryptography, GCC, glibc, OpenSSL 3, unittest.
