# Test apps

`android/InsecureBankv2.aab` is an Android App Bundle of InsecureBankv2, package `com.android.insecurebankv2`. The AAB tests in `tests/rasp_packer/android/aab/` use it: `manifest_test.py`, `packer_test.py` and `proto_manifest_test.py`.

InsecureBankv2 comes from [`Android-InsecureBankv2`](https://github.com/dineshshetty/Android-InsecureBankv2), under the MIT licence.
